# 魔法小屋（Magic House）

> 当前开发版 v0.9.0（2026-09-24）：新增 4 个中央十字路口世界房间（游乐场 playground / 宠物店 petstore /
> 烘焙坊 bakery / 娃娃屋 dollhouse），地图 9 格全部可点；学校、公园、商店、游乐场、宠物店、烘焙坊、娃娃屋
> 仅从地图进入，房间选择器保留 7 个常用入口；sw.js 缓存版本按内容哈希自动推进。
> （sw.js 里的 `VERSION` 是内容哈希，与这里的语义版本号解耦。）

给 4 岁半小朋友的装扮游戏：**换装、布置房间、做好吃的**。
纯静态网页（HTML/CSS/JS，零依赖零构建）；绝大多数美术由代码生成 SVG，地图地点使用 PNG 素材。

## 玩法

- **大世界**：默认是地图屏；点大房子进入卧室，点换房间按钮可直达 7 个常用房间；
  14 个世界房间（学校、院子、公园、商店、游乐场、宠物店、烘焙坊、娃娃屋）从地图进入，手指左右拖动看世界
- **娃娃会走路**：点一下地板娃娃就走过去；按住娃娃 / 小猫可以拎到任何场景
- **学校**：点地图右下角的学校进入教室，使用黑板、书桌、椅子、皮球和铅笔盒布置自己的小课堂
- **游乐场**（v0.9 新）：点地图中央靠上的游乐场进入玩旋转木马 / 跷跷板 / 滑梯 / 海洋球池 / 长椅
- **宠物店**（v0.9 新）：点地图中央靠左的宠物店看小狗小猫鱼缸狗粮袋宠物床
- **烘焙坊**（v0.9 新）：点地图中央靠右的烘焙坊用烤箱蛋糕饼干面粉袋擀面杖做糕点
- **娃娃屋**（v0.9 新）：点地图中央靠下的娃娃屋布置迷你床迷你沙发迷你桌子迷你灯迷你相框
- **换衣间**：小女孩纸娃娃（6 发型 × 6 发色 × 8 裙子 × 6 鞋 × 6 配饰）+ 小猫伙伴
  （4 配件），点卧室里的大衣柜进来；衣柜可拖到墙边，换装页点“返回房间”即可回去
- **布置房间**：每个房间一套家具（8~13 件，含贴纸）可随意摆放拖动，9 种墙纸 9 种地板一键换
- **厨房**：点冰箱拿 15 种食物喂给娃娃和小猫；点灶台可做 5 道菜（水果沙拉 / 煮面条 /
  小蛋糕 / 果汁 / 冰淇淋），选菜谱 → 点食材放进锅 → 手指在锅里画圈搅拌 → 魔法按钮 → 喂食
- **收走东西**：把家具或食物拖到屏幕下方的收纳筐，或点左下角垃圾桶按钮再点要收走的东西

特点：零文字零规则、大触控目标、永不失败、自动存档（localStorage）、
合成音效 + 中文语音夸奖（TTS）、PWA 离线全屏运行。

## 部署（GitHub Pages）

```
node deploy.mjs       # 建仓/上传/开启 Pages
node sync-push.mjs    # github.com:443 不通时的备选：只走 api.github.com
```

两个脚本都会先跑 `bump-sw.mjs`：按离线缓存清单里各文件的内容算出哈希并写回 sw.js 的
`VERSION`。sw.js 的 fetch 是 cache-first，浏览器只在 sw.js **字节变化**时才装新
Service Worker —— 有了这步，改了 js/css 忘记改版本号也不会让 iPad 上已安装的老用户
一直吃旧缓存。同一份内容重复跑不会产生改动。

推送 main 分支后开启 Pages 即可。iPad 上用 Safari 打开网址 →
分享 → 添加到主屏幕 → 全屏离线运行。

以后想转原生 iOS App：用 Capacitor 直接打包这套代码，在 iMac 上编译即可。

## 目录

```
index.html            入口（PWA meta）
manifest.webmanifest  PWA 清单
sw.js                 Service Worker（离线缓存；VERSION 由 bump-sw.mjs 自动生成）
css/style.css         全部样式
js/                   store/audio/fx + 三个素材库 + 三个模块 + main
icons/                应用图标（SVG 源 + PNG）
server.js             本地预览服务器
test-auto.html        自动化测试页（143 项）
bump-sw.mjs           sw.js 版本按内容哈希自动推进（顺带体检 CORE 是否漏文件）
deploy.mjs            一键部署到 GitHub Pages
sync-push.mjs         github.com 不通时的 API 同步推送
```
